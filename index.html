How I work with data

Three habits behind every analysis I do.

  1. 01 · Measure

    Models, judged honestly

    I build models on open data and judge them by what they catch, not by a flattering accuracy score.

  2. 02 · Focus

    Segments that guide action

    Segmentation shows which customers matter most, so effort goes where it pays off.

  3. 03 · Explain

    Charts people can read

    Dashboards and one-line takeaways that someone outside the data team can act on.

Analyses on public data

Public datasets, clear questions, honest answers.

  1. Churn analysis

    Which bank customers leave?

    10,000 customers, 20% left; among women, 25%. The group that stands out: women aged 45–54 with a fair credit score. More than half of them (53%) left.

    • pandas
    • scikit-learn

  2. RFM segmentation

    Which customers matter most?

    89 customers in 9 segments. The Champions segment is 12% of customers and brings in 29% of revenue.

    • pandas
    • seaborn
    View on GitHub (opens in a new tab)
  3. A/B test

    Where should a mobile game make players wait?

    90,189 players. Moving the first gate from level 30 to level 40 lowered 7-day retention from 19.0% to 18.2%, so level 30 works better.

    • pandas
    • SciPy
    View on GitHub (opens in a new tab)
  4. Regression

    What drives medical costs?

    Smoking dominates: smokers average $32,050, non-smokers $8,441. The tuned decision tree explains 77% of the differences in cost.

      Side project

      Offline Slide Studio

      An offline slide studio in a single HTML file: paste a table from Excel, pick one of 23 chart types and export the card as PNG, SVG or PowerPoint. No server, no install, no internet.
